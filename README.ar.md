# مستخرج موسيقى الملف الشخصي في تيليجرام

سكربت Telethon صغير ينزّل الصوتيات المحفوظة في **تبويب الموسيقى** بملفك الشخصي في تيليجرام («حفظ الموسيقى في الملف الشخصي») ويجمعها في ملف `profile_songs.zip` واحد.

## ماذا يفعل

يسجّل السكربت الدخول بحسابك، ويطلب معرّفات الموسيقى المحفوظة من ملفك الشخصي، ويحوّل كل معرّف إلى رسالة صوتية وينزّلها في مجلد مؤقت `profile_songs/`. وعند الانتهاء يضغط المجلد ويحذف الملفات الفردية.

وإذا فشل طلب موسيقى الملف الشخصي أو لم يدعمه حسابك، يعود السكربت إلى فحص **الرسائل المحفوظة** بحثًا عن ملفات صوتية.

## المميزات

- استخراج موسيقى الملف الشخصي عبر `account.GetSavedMusicIds`.
- فحص احتياطي للرسائل المحفوظة عند تعذّر موسيقى الملف الشخصي.
- إنشاء ZIP تلقائيًا وتنظيف المجلد المؤقت.
- يتجاهل أي شيء ليس رسالة صوتية.

## المتطلبات

- Python 3.10 أو أحدث
- Telethon
- حساب تيليجرام وبيانات API من [my.telegram.org](https://my.telegram.org)

## الإعداد

```bash
git clone https://github.com/kasdo-iq/telegram-saved-music-extractor.git
cd telegram-saved-music-extractor
python -m venv .venv
source .venv/bin/activate          # Windows: .\.venv\Scripts\Activate.ps1
pip install telethon
```

افتح `telegram_music_extractor.py` واستبدل القيم الثلاث في الأعلى:

```python
API_ID = 'YOUR_API_ID'
API_HASH = 'YOUR_API_HASH'
PHONE = 'YOUR_PHONE_NUMBER'
```

في أول تشغيل يطلب Telethon رمز الدخول (وكلمة مرور التحقق بخطوتين إن كانت مفعّلة)، وينشئ `session_name.session` في مجلد العمل.

## الاستخدام

```bash
python telegram_music_extractor.py
```

يطبع السكربت تقدم كل أغنية ويكتب الأرشيف في المجلد الحالي:

```text
profile_songs.zip
```

وإذا لم يجد أغاني، لا ينزّل شيئًا ويحذف المجلد المؤقت.

## الإعدادات

كل الإعدادات أعلى `telegram_music_extractor.py`، ولا يوجد ملف `.env`.

| الإعداد | الوصف |
|---|---|
| `API_ID` | معرّف API من my.telegram.org. |
| `API_HASH` | مفتاح API من my.telegram.org. |
| `PHONE` | رقم الهاتف بالصيغة الدولية لأول دخول. |

ملفات وقت التشغيل:

- `session_name.session` — جلسة الدخول. **سرّية**؛ تمنح الوصول إلى الحساب.
- `profile_songs/` — تنزيلات مؤقتة تُحذف بعد الضغط.
- `profile_songs.zip` — الأرشيف الناتج.

الثلاثة مغطاة في `.gitignore`.

## التحقق

لا توجد اختبارات آلية. لفحص نحوي دون بيانات اعتماد:

```bash
python -m compileall -q telegram_music_extractor.py
```

## القيود

- واجهة موسيقى الملف الشخصي حديثة نسبيًا. في إصدارات Telethon أو طبقات الحساب الأقدم قد يفشل الطلب، ويعود السكربت حينها إلى **كل الصوتيات في الرسائل المحفوظة**، وقد تشمل ملفات ليست موسيقى الملف الشخصي.
- اسم الملف الناتج ثابت (`profile_songs.zip`)؛ تشغيل السكربت مرتين في المجلد نفسه يستبدل الأرشيف السابق.
- تُحذف الملفات المنزّلة بعد الضغط، لذا احتفظ بملف ZIP إن أردت نسخة احتياطية.

## الاستخدام المسؤول

- استخدم الأداة مع حسابك وموسيقاك المحفوظة فقط.
- ملفات الموسيقى محمية بحقوق النشر. لا توزّع الأرشيف ولا تستخدمه لبناء مكتبة عامة.
- احفظ ملف الجلسة خاصًا ولا ترفعه أبدًا.
